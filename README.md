## 💻 Run Locally

Clone the repository

```bash
git clone https://github.com/Aditya-Vishwakarma722/Portfolio-Prototype.git
```

Go to the project folder

```bash
cd Aditya-Portfolio
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
